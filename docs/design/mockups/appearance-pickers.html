Appearance pickers — F4 & F5

The confirmed interaction design with the real curated preset lists: 11 themes, 20 fonts. Both dropdowns use the same fixed-height / hidden-scrollbar treatment as .progress-box-list; saved themes and imported fonts scroll past the fixed edge rather than growing the dropdown.

F4 · theme dropdown — 3 rows, scrolls

"Create your own theme" is its own row above the grid — same pattern as "Upload a font" — so it stays reachable no matter how many saved themes are scrolled past. Opens the edit modal for a new theme. Hover a saved swatch for a pencil (edit, bottom-right) and × (delete, top-right).

F5 · font dropdown — 5 rows, scrolls

Grotesk-Bold.woff2

"Upload a font" is its own row above the grid so it stays reachable no matter how far the list is scrolled. Picking a file expands the inline name row — never a second popup. Imported fonts get the same hover-reveal × (delete only; no rename).
