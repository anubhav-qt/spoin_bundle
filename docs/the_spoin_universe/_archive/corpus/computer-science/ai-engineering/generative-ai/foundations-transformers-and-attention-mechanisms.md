## Scaled Dot-Product Attention from First Principles
At the architectural foundation of modern generative artificial intelligence lies the Scaled Dot-Product Attention mechanism, formalized by Ashish Vaswani and collaborators in 2017. Attention computes a dynamic, content-dependent routing of information across sequence tokens by mapping a set of Queries ($Q \in \mathbb{R}^{N \times d_k}$), Keys ($K \in \mathbb{R}^{M \times d_k}$), and Values ($V \in \mathbb{R}^{M \times d_v}$). The mathematical formulation is defined as $\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$. The projection product $QK^T$ evaluates pairwise affinity scores between every query token and all candidate key tokens. The scaling denominator $\sqrt{d_k}$ (the square root of the key dimension) serves a vital numerical stabilization role: for large dimensional vectors, dot products grow substantially in magnitude, pushing the subsequent softmax function into regions characterized by vanishingly small gradients. Applying softmax normalizes these raw affinity scores into a row-stochastic attention weight matrix representing probability distributions across the sequence, which subsequently computes a weighted sum over the value vectors $V$. Unlike recurrent neural networks (RNNs) that process text sequentially with $O(N)$ sequential operations, the Transformer architecture computes self-attention across all tokens simultaneously, unlocking massive parallelization on modern GPU Tensor Cores.

## Attention Architectures: MHA, MQA, and Grouped-Query Attention
While foundational self-attention utilizes Multi-Head Attention (MHA)—where queries, keys, and values are partitioned into $H$ independent parallel representation subspaces—the operational reality of deploying large language models introduced severe memory bottlenecks. In autoregressive token generation, the Key-Value (KV) cache must retain the key and value vectors of every previous token across all layers in high-bandwidth GPU memory (HBM) to avoid redundant computation. Under MHA, where each query head possesses its own dedicated key and value head ($H_q = H_{kv}$), the memory footprint of the KV cache scales linearly with batch size, context length, layer count, and head count, consuming tens of gigabytes of VRAM. To resolve this, Noam Shazeer introduced Multi-Query Attention (MQA), collapsing all key and value heads into a single shared head ($H_{kv} = 1$) while retaining multiple query heads ($H_q > 1$). While MQA slashes KV cache memory by up to $8\times$ and accelerates generation speed, it can degrade fine-grained semantic representation in reasoning and multi-hop tasks. Joshua Ainslie and colleagues engineered the industry-standard compromise: Grouped-Query Attention (GQA). GQA divides query heads into $G$ balanced groups, with each group sharing a single key and value head ($1 < H_{kv} < H_q$, typically an 8:1 ratio as seen in Llama 3). GQA captures virtually all the expressivity and accuracy of full MHA while maintaining the high throughput and low memory footprint of MQA.

## Multi-Head Latent Attention (MLA) and KV Cache Compression
Introduced by DeepSeek in the DeepSeek-V2 and DeepSeek-V3 frontier architectures, Multi-Head Latent Attention (MLA) represents a revolutionary paradigm shift in attention engineering, addressing the explosive memory demands of multi-hundred-thousand token context windows. Standard GQA still caches high-dimensional vectors for every token in every layer. MLA solves this by implementing low-rank joint compression: instead of projecting hidden states directly into high-dimensional key and value heads, the projection maps hidden activations $\mathbf{h}_t$ into a compact, low-dimensional latent vector $\mathbf{c}_t^{KV} \in \mathbb{R}^{d_c}$ where $d_c \ll d_k \cdot H$. During autoregressive generation, only this compressed latent vector $\mathbf{c}_t^{KV}$ is stored in the KV cache, slashing the physical memory footprint by over 90% compared to traditional MHA. When computing attention, full key and value states are reconstructed on the fly via up-projection matrices. Furthermore, MLA employs an algebraic "weight absorption" technique: during inference, the up-projection matrices are mathematically absorbed and fused directly into the query projection matrices ($W_Q$), allowing the attention mechanism to execute as standard matrix multiplications without ever materializing decompressed keys in GPU memory. MLA fundamentally alters the economics of long-context inference, enabling frontier-class 671B parameter models to serve 128k token contexts with negligible cache overhead.

## Normalization, Activation Functions, and SwiGLU Gating
The internal building blocks of modern Transformer decoder layers have evolved substantially beyond the original 2017 specifications to enhance gradient flow and training stability at massive scale. In early architectures, Post-Layer Normalization placed LayerNorm operations after the residual additions, causing severe gradient vanishing and instability during the initial phases of deep network training. Modern foundational models universally adopt Pre-Layer Normalization, normalizing activations prior to entering attention and feed-forward blocks, which maintains an unobstructed residual highway throughout the network. Furthermore, standard LayerNorm has been replaced by Root Mean Square Normalization (RMSNorm). By eliminating the computationally expensive mean-centering calculation and computing only the root mean square of activation inputs ($\bar{a}_i = \frac{a_i}{\text{RMS}(\mathbf{a})} g_i$), RMSNorm reduces normalization overhead by 10% to 20% while preserving identical numerical stability. In the Feed-Forward Network (FFN), traditional ReLU and GELU activation functions have been superseded by SwiGLU (Swish-Gated Linear Unit). Formalized by Noam Shazeer, SwiGLU replaces single-path non-linearities with a bilinear gating mechanism: $\text{SwiGLU}(x) = (x W_1) \cdot \text{Swish}(x W_2) W_3$. The gating branch dynamically scales the activation flow, consistently yielding lower perplexity and accelerated convergence across billions of pre-training tokens.

## Positional Encodings: Rotary Embeddings (RoPE) and YaRN Context Scaling
Because self-attention is mathematically permutation-equivariant—treating an unordered set of tokens identically to an ordered sentence—Transformers require explicit positional encodings. Early approaches relied on static sinusoidal vectors added to input embeddings, which decayed poorly when extrapolating to sequences longer than those seen during training. The modern universal standard is Rotary Position Embedding (RoPE), formulated by Jianlin Su. RoPE encodes absolute position by interpreting query and key vectors as pairs of two-dimensional complex numbers, rotating them in the complex plane by an angle proportional to their sequence index $m$: $\mathbf{q}_m = \mathbf{R}_{\Theta, m} W_Q \mathbf{x}_m$. The inner product between rotated queries and keys naturally incorporates relative distance ($\mathbf{q}_m^T \mathbf{k}_n = g(\mathbf{x}_m, \mathbf{x}_n, m - n)$), decaying gracefully as token distance increases. To extend pre-trained models from native 8k context lengths to 128k or 1M tokens, modern architectures implement YaRN (Yet another RoPE extensioN). YaRN recognizes that high-frequency Fourier components in RoPE encode local semantic relationships and must be extrapolated, whereas low-frequency components encode global narrative context and must be interpolated. By applying non-uniform, dimension-specific frequency scaling, YaRN enables seamless, distortion-free context extension with minimal post-training fine-tuning.
