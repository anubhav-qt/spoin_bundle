# `temp/` — research scratch

Raw research output for the **one** survey or topic currently being authored.
See [`../procedure.md`](../procedure.md), Phase D.

**This directory is wiped and rewritten at the start of every run**, and its contents
are gitignored. Nothing here is ever ingested into `the_spoin_universe`, and nothing
here is a deliverable — the deliverable is the curated result under `../corpus/`.

Clear it when a run *starts*, not when it ends: a run that dies halfway should leave
its evidence behind rather than having tidied it away first.

This README is committed so the directory survives; everything beside it does not.
