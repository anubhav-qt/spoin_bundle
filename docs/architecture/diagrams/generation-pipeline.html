Spoin Generation Pipeline

Every step a topic passes through, from topic accepted to cards + questions persisted — drawn exactly as the code stands in the current working tree (ADR‑0066 ASCII redraw and ADR‑0065 quota terminal states applied, uncommitted; all tests green).

Two physical model pools exist in langchain_impl.py: THINKER (self._thinking, RPD 20/cell) and GENERATOR (self._generator, RPD 500/cell). PLANNER is a role (plan_cards, ADR‑0059), not a pool — it rides the GENERATOR pool and spends GENERATOR quota. Local checks (embedding dedup, ASCII width, difficulty re‑rating) touch no LLM.
