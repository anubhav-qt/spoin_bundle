B14 · ADR-0076

Report a card

A flag control in the card action row, next to Ask AI. One tap opens a reason picker in the same popover chrome as Share. The note is optional; re-reporting the same card just updates the row.

1 · Action row — flag added between Note and Share

Why meanders migrate downstream
Erosion on the outer bank, deposition on the inner — the bend crawls.

Flag icon uses --accent border+ink (like a toggled action) so it reads as “flaggable”, not destructive.

2 · Popover open — reason picked, note optional

What’s wrong with this card?

Before a reason is picked, Report is disabled. Chrome, radius, shadow and enter-animation are the existing .share-popover.

3 · After submit — quiet confirmation, then closes

Thanks — flagged for review.

Auto-dismisses after ~1.4s. No toast, no feed disruption — the report is a moderation signal, not an engagement event.
